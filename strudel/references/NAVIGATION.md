# Strudel Skill Reference Library

This skill vendors a full reference library (docs + reference index + curated compositions) and a small set of guides.
Use this file as the entry point.

## Quick Routing (What to open first)

### I need to write playable Strudel quickly

1. `references/guides/anchor-framework.md`
2. `references/guides/walkthroughs.md`
3. If you need more patterns/FX: `references/guides/cookbook.md`

### I need to understand mini-notation / pattern operators

- `references/docs/patterns_and_notation.md`

### I need to pick sounds / instruments

- `references/sounds/synths.txt`
- `references/sounds/samples.txt`
- `references/sounds/drum-machines.txt`
- `references/sounds/wavetables.txt`

### I need to look up a Strudel function (source of truth)

1. `references/ref/strudel_reference_INDEX.txt` (find which file contains the function)
2. Open the corresponding alphabetical file:
   - `references/ref/strudel_reference_A-C.txt`
   - `references/ref/strudel_reference_D-F.txt`
   - `references/ref/strudel_reference_G-J.txt`
   - `references/ref/strudel_reference_K-O.txt`
   - `references/ref/strudel_reference_P-R.txt`
   - `references/ref/strudel_reference_S-Z.txt`
3. For one-line reminders: `references/ref/strudel_reference_QUICK_LOOKUP.txt`
