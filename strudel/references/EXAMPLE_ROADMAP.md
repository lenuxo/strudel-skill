# Example Roadmap

This is a lightweight guide to the most useful examples in this skill.

## If you want a “complete piece” that evolves step-by-step

Read these first (they show a repeatable method):

- `references/compositions/process/eminor_composition_process.js`
- `references/compositions/process/dminor_composition_process.js`
- `references/compositions/process/lydian_composition_process.js`

Then keep `references/methods/syncopations.txt` open as your transform palette.

## If you want ready-made idioms (short and reusable)

- `references/guides/snippets.md`
- `references/guides/cookbook.md`

## If you need authoritative API details

- `references/ref/strudel_reference_INDEX.txt` + the matching A-C/D-F/... file

## If you need “why” explanations

- `references/docs/patterns_and_notation.md` (mini-notation + transforms)
- `references/docs/audio_and_synthesis.md` (signal chain + FX rules)
- `references/docs/musical_theory.md` (scales/chords/voicings)
- `references/docs/samples_and_sounds.md` (samples + banks + variants)
